# ADR-006: Database Access & Migrations (Drizzle ORM with Custom SQL Migrations)

**Status:** Accepted

## Context

Aureon requires type-safe SQL query construction, zero runtime code-generation overhead, precise control over PostgreSQL Row-Level Security (RLS) policies, and deterministic migration execution.

## Decision

Use Drizzle ORM for schema definition and query building, paired with Drizzle Kit for declarative schema generation and custom SQL migration files for RLS policies, triggers, and extensions. Verified by Spike S2 that drizzle-kit drift checks report 'No schema changes' when custom RLS SQL migrations are applied.

## Alternatives

- **Prisma:** Heavy Rust query engine binary, lacks native support for PostgreSQL Row-Level Security policies, and incurs runtime object mapping overhead.
- **Kysely:** Excellent query builder, but Drizzle provides more ergonomic schema-to-type inference and migration orchestration.
- **Raw SQL (node-pg):** Error-prone, lacks compile-time column safety and autocompletion for application queries.

## Consequences

- **Positive:** High performance, thin abstraction over pg, full TypeScript type safety, and seamless custom SQL migrations.
- **Negative:** Schema migrations require careful review when adding RLS policies or PostgreSQL-specific constructs.
