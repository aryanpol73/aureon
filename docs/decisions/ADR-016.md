# ADR-016: Memory System Scope for v1 and Decisions Entity

**Status:** Accepted

## Context

AI agents require historical memory to personalize assistance, but automatic, unconstrained memory extraction frequently captures hallucinations, transient chatter, or unauthorized data.

## Decision

Scope v1 Memory to semantic and project memory with strict human-in-the-loop controls:

- Memory Sources: (a) Explicit memories created directly by the user (status: active, verified_by: user); (b) Memories proposed by AI strictly from user messages (status: proposed, excluded from context until confirmed).
- Strict Ingestion Filter: Extraction only processes HistoryMessage with role='user'. Retrieved documents, tool outputs, and assistant messages are forbidden sources.
- First-Class Decisions Entity: Decisions are tracked in the planning domain as relational entities (proposed, accepted, superseded, reversed) with typed links and rationales.
- Episodic Memory: Deferred post-v1.

## Alternatives

- **Unconstrained autonomous memory extraction:** Results in polluted context, hallucinations, and loss of user trust.
- **No memory system:** Forces the user to re-explain preferences and project context in every conversation session.

## Consequences

- **Positive:** High memory accuracy, strong user privacy and trust, and deterministic audit trail of key decisions.
- **Negative:** Users must periodically review and confirm proposed memories.
