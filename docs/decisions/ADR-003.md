# ADR-003: Web Frontend Framework (Next.js App Router and React 19)

**Status:** Accepted

## Context

The Aureon web client requires server-side rendering for initial load performance, streaming Server-Sent Events for real-time agent output, secure HTTP-only cookie handling, and responsive desktop/mobile layouts.

## Decision

Adopt Next.js (App Router) with React 19. The web application acts purely as a consumer of the backend API, importing shared TypeScript contract definitions directly from packages/contracts. The web app contains no direct database connections or private secrets.

## Alternatives

- **Vite + React SPA:** Lightweight, but lacks seamless SSR, edge routing, and built-in streaming SSR ergonomics.
- **Remix / React Router 7:** Excellent routing model, but Next.js offers wider ecosystem alignment and mature App Router streaming primitives.

## Consequences

- **Positive:** High performance streaming rendering, unified TypeScript models with backend via contracts package, and isolated security surface.
- **Negative:** Next.js releases must be vetted for security advisories (e.g. React2Shell CVE-2025-55182, Next.js CVE-2025-29927) before upgrading.
