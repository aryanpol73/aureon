# Aureon

Aureon is an AI-powered Personal Operating System and Personal Intelligence Platform designed to unify knowledge, documents, notes, projects, tasks, goals, decisions, and long-term memory with grounded contextual reasoning. The codebase is currently at **Milestone 1.1a (Engineering Foundation Only)**, providing the root workspace configuration, strict TypeScript baseline, formatting, the core `Clock` port abstraction, CI automation, and architectural documentation.

For architecture decisions, setup guides, and spike results, see the [Architecture Documentation](docs/architecture/000-kickoff.md), [Architecture Decision Records (ADRs)](docs/decisions/ADR-001.md), [Spike Results](docs/spikes/m1.0-results.md), and [Getting Started Guide](docs/development/getting-started.md).
